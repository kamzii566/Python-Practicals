# Practical 1: Roots of a Quadratic Equation

## Aim
To write a Python program to calculate the roots of a quadratic equation.

## Theory
A quadratic equation is represented as:

**ax² + bx + c = 0**

The discriminant is calculated using:

**D = b² - 4ac**

- If D > 0, the equation has two distinct real roots.
- If D = 0, the equation has two equal real roots.
- If D < 0, the equation has two complex roots.

## Algorithm
1. Start the program.
2. Input the coefficients a, b, and c.
3. Calculate the discriminant using D = b² - 4ac.
4. Calculate the roots based on the discriminant.
5. Display the roots.
6. Stop the program.

## Python Program
See `practical1.py` in this folder.

## Sample Input
```text
Enter a: 1
Enter b: -5
Enter c: 6
```

## Expected Output
```text
Roots are: 3.0 and 2.0
```

## Conclusion
The Python program calculates the roots of a quadratic equation using the discriminant.
